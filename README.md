# fs-whiteboard

FreeSynergy program for boards: an infinite canvas where every shape, note and stroke is an object with an id that can be searched, referred to and reused.

* `crates/fs-whiteboard-core`: the program core (no GUI, no capnp server yet). See `DESIGN.md`.
* The contract is `whiteboard.capnp` in [fs-interfaces](https://github.com/FreeSynergy/fs-interfaces) (tag v0.26.0).
